# 日序 · RSI Releases

日序 macOS 的公开安装包与更新清单，源码在独立私有仓库维护。

[下载最新版本](https://github.com/jronald1024/RSI-Releases/releases/latest)

- Apple Silicon 用户下载名称中带 `arm64` 的 DMG，打开后将日序移至应用程序。
- ZIP 用于应用内更新；应用及 DMG 使用原 Developer ID 签名并经 Apple 公证。
- App 自动优先检查 GitHub，失败后尝试已有 OneDrive 发布目录。菜单「查看更新日志」显示实际来源。
- GitHub 保留最新 10 个由发布流程管理的正式版本；历史安装包在发布者 OneDrive 中归档。
- 本仓库不包含个人资料、源码、私钥或发布凭据。
